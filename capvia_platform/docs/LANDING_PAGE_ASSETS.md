# CAPVIA Landing Page Assets

## Icons
- **Lucide React:** Used for consistent, scalable, and customizable SVG icons across the page.
- **Brand Icons:** Rendered via SVG paths or generic representative icons from Lucide where applicable.

## Images
*Note: Placeholder generic high-quality SVG structures and gradients are used in the absence of specific graphic assets to maintain a premium feel.*

- **Dashboard Previews:** SVG representations of UI elements (charts, tables, cards).
- **Company Logos:** Text-based representations styled to look like corporate logos.
- **Avatars:** Circle elements with subtle gradients representing users in testimonials.

## Animations
- **Framer Motion:** Used for smooth entry animations, hover effects, and scroll-triggered reveals.
- **CSS Transitions:** Applied to buttons and interactive elements for immediate feedback.
