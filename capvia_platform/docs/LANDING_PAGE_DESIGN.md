# CAPVIA Landing Page Design System

## Overview
The CAPVIA landing page has been redesigned to reflect a world-class SaaS product, prioritizing trust, innovation, intelligence, enterprise, AI, hiring, and professionalism. The design is heavily inspired by industry leaders like Apple, Stripe, Linear, Vercel, Framer, Notion, and OpenAI.

## Color Palette
- **Primary:** `#0D47A1` (Deep Blue - Trust, Enterprise)
- **Secondary:** `#42A5F5` (Light Blue - Innovation, Intelligence)
- **Accent:** `#FFC107` (Amber - Action, Highlight)
- **Background:** `White` (Clean, Professional)
- **Neutral:** `Gray` scale for typography and subtle borders.

*Note: No dark theme or neon colors are used per constraints.*

## Typography
- **Primary Font:** Outfit (Headings)
- **Secondary Font:** Inter (Body Text)
- **Styling:** Vercel-quality typography with crisp rendering, proper tracking, and legible line heights.

## Layout & Spacing
- **Spacing:** Apple-level spacing with generous white space to let elements breathe.
- **Grids:** Strict 12-column grid system for large screens, degrading gracefully to 8 and 4 columns for tablet and mobile.

## Visual Elements
- **Gradients:** Stripe-quality subtle background gradients to add depth without being overwhelming.
- **Cards:** Linear-quality cards with refined shadows, subtle borders (glassmorphism touches), and clear visual hierarchy.
